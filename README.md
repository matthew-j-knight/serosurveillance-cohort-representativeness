Repository for manuscript "SOCIODEMOGRAPHIC CHARACTERISTICS OF SARS-CoV-2 SEROSURVEILLANCE STUDIES WITH DIVERSE RECRUITMENT STRATEGIES, CANADA, 2020 TO 2023". doi:10.1186/s12889-025-22975-y 

The repository contains all code used for analyses and to develop the manuscript. The 1_data folder is empty because we are not permitted to share individual line-level data from any study. Because of this, our repo cannot be used to replicate this analysis. Processes are available for researchers to request access to datasets for studies that have undergone institutional ethical approval.
